Install & Run Locally

      

        Download a prebuilt binary from GitHub Releases (no Rust toolchain required) or install from source with Cargo:
      

      
# Prebuilt binaries (Windows / macOS arm64 & x64 / Linux):
# https://github.com/oceans-niagara/guardrails/releases/latest
#   Windows: .\guardrails-windows-x86_64.exe init && .\guardrails-windows-x86_64.exe check
#   macOS:   chmod +x ./guardrails-macos-arm64 && ./guardrails-macos-arm64 init && ./guardrails-macos-arm64 check

# Or build from source:
cargo install --git https://github.com/oceans-niagara/guardrails
guardrails init
guardrails check --config guardrails.toml --format sarif
